# University Course Registration Database

## Overview

This repository contains a database project for a University Course Registration System. The project is designed to organize and manage information about students, courses, instructors, departments, and course enrollments.

## Project Documentation

The initial project proposal is available in [`docs/proposal.md`](docs/proposal.md).

## Repository Structure

```text
university-course-database/
├── README.md
└── docs/
    └── proposal.md
```

## Project Goals

The database will provide a structured way to store university registration data and will eventually support queries about student enrollments, courses, instructors, departments, and academic results.
